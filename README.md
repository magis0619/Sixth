# 🌱 畑スロット

スロットを1回転するたびに畑で1日分の出来事が起き、出目を畑のどこに使うかで作物を育てて売るゲーム。
中心の悩みは「陣取り」：縦・横・斜めに3つ並べた作物は列ごと高く売れる。

公開URL：https://magis0619.github.io/Sixth/

## 遊び方

1. スタート → 準備画面（今回ショップに並べる強化と難しさを選ぶ）→ プレイ
2. 「まわす」で1日進む。手動の出目（種・雨・太陽・蜂・満月・雷・肥料）はタップ → 畑のマスをタップで使う
   - 雨＝縦横十字、太陽＝縦一列、蜂＝斜め、雷＝横一列+2、満月＝タップだけで畑全体
3. 自動の出目（カラス・虫・金貨・商人・四つ葉・雑草・タヌキ・霜）は止まった瞬間に効く
4. 実った作物をタップで売る。縦・横・斜めに3つ並ぶと列ごと売れて×1.3、同じ作物だけの列はさらに×1.3、交差は+15%。単品は半値
5. 7日ごとに年貢。払えないと終わり。7回納める（49日目）とクリア（続けるとエンドレス）
6. 年貢のあと：お守りを3つから1つ選ぶ。代わりにお邪魔が袋に増える（回を追うごとに多く強く）
7. ショップ：絵柄を足す・お邪魔を消す（週1回まで・消すたび高くなる）・満月・道具（かかし・井戸・巣箱・鶏小屋・牛小屋）・特別なマス（堆肥・水路）・畑を広げる（最大5×5）
8. スイカ：2×2マスを占める大物。列には入らず、1個で高く売れる（単品でも半値にならない）
9. 鍬：横一列の雑草・霜を消して耕す。耕した土に植えると成長+1。モグラ（お邪魔）は作物を隣の空きマスへ押し出す
10. 水路のつながり：3つ以上まっすぐ並べると水車（並べた数×1金/晩）、空きマスの4方を水路で囲むと釣り堀（毎晩お金、ときどき大物。畑の端は囲みにならない）。鶏小屋・牛小屋も毎晩お金が入る。鶏小屋は周りの虫を食べ、モグラを追い払う
11. 相場（一時停止中）：週ごとに1品が高値（×1.5）・1品が安値（×0.7）。畑の右上の札
12. シナジー：巣箱の周りの苺は毎晩育つ／水車の立った水路の隣のマスは毎晩育つ／牛小屋の隣に水路で収入+2／太陽は縦一列の霜を溶かす
13. セット効果：牧場（鶏小屋・牛小屋・巣箱がそろうと3つとも2倍）、彩りの畑（実った作物が4種類以上で売値+10%。そろった日は売って減ってもその日のうちは続く）
14. お守り：牧場主（小屋の収入+1）・大物狙い（スイカ+30、スイカを使えるゲームだけ）・水車職人（水車×2）・耕作上手（耕した土で成長+2）

## 試し中のルール：毎日の仕入れ

- 毎日、回したあとにスロットの看板へ3つの絵柄が並ぶ。1つ選ぶとタダで袋に入る（選ばなければ翌日に消える）
- ショップで足せる絵柄は満月だけ。ショップは畑の道具・お邪魔を消す品・満月
- 戻すとき：src/config.ts の `dailyPick` を false にする（前の「週替わりの3品をショップで買う」に戻る）。導入前のコミットは baf8730
- シミュレーター：`DAILY=0 npm run sim -- 400 starter smart` で前のルールと比べられる

## 遊ぶ人向けの機能

- タイトル：スタート・続きから・解放・遊び方・記録（遊んだ回数・クリア・最高到達など）・設定
- 設定：言語（日本語 / English）・BGMの大きさ・効果音の大きさ・音を消す・振動・演出をはやく・演出控えめ・遊んだ記録を送る（送り先があるとき）・データを消す（2回押し）・書体と版の表記
- ゲーム中のメニュー（≡）：遊び方・音・演出・設定・タイトルへ（途中は自動で保存）
- 終わりの画面：振り返り（年貢まであと何金・一番稼いだ日・列の数）と次に試すことのひと言、もう一度・タイトルへ
- BGM：その場で合成するのんびりした曲（素材ファイルなし）。大きな演出の間は小さくなる
- 英語表示：端末が日本語以外なら英語で始まる。設定でいつでも切り替え（src/i18n.ts の L(日本語, 英語)）
- ホーム画面に置ける（PWA）。一度開けば電波がなくても遊べる。共有したときの絵（og.png）つき

## 条件で開くもの

- プレイ中：袋の中身で開く特別なお守り（雷雨・トマト祭り・天気雨・月の宴）、出来事でもらえるお守り（大豊作＝畑いっぱいを一度に売る・1プレイ1回の大当たり、カラス返し・首の皮・品評会＝作物を全6種類売る。品評会は一時停止中）
- 進化：同じお守り3個で金色（効果2倍）、道具は働くと上位の道具になる
- ゲームの外：メロン（初クリア）、雷（累計で列100回）、難しいモード5段階（1つ下をクリア。難しさは積み重なり、難しい5は袋の中で増えるイナゴ）、金色のスロット（初クリア）
- 遊び終わると豊穣ポイント（日数×0.5＋年貢×3、クリアで+20）。スタート画面の「解放」で強化やレアのお守りを解放。図鑑もここ

## プレイ記録（統計）

年貢ごとの途中経過と1プレイの結果を Google スプレッドシートに送れる。
受け口の作り方は `scripts/telemetry-apps-script.gs` の先頭。公開したURLを `src/config.ts` の `TELEMETRY_URL` に入れると送信が始まる（空なら送らない）。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック＋ビルド（dist/）
npm run sim -- 800 starter smart   # ボットでバランス確認（smart＝考えて置く / random＝適当に置く）
DIFF=2 npm run sim -- 400 starter smart   # 難しいモード
npm test         # ルールの単体テスト（vitest）
npm run e2e      # 画面の通し確認（Playwright。ビルドしてから）
npm run audit    # 画面の総点検：4サイズ×全画面を撮って、はみ出し・重なりを数える（vite preview を出してから）
```

- push するとどのブランチでも GitHub Actions で型チェック・単体テスト・ビルド・通し確認が走る

- 調整用パラメータはすべて `src/config.ts`
- ルール本体は `src/game.ts`（画面に依存しない）、遊ぶたびに増える要素は `src/meta.ts`
- 画面：`src/main.ts`（描画と操作の流れ：回す・使う・売る・買う）と `src/ui/`
  - `store.ts` 画面の要素と共有の状態（`state` は `setState` で差し替え、`hooks` で main の処理を呼ぶ）
  - `view.ts` 表示の部品 / `screens.ts` タイトル・準備・解放・遊び方・結果・クリア / `shows.ts` 年貢・お守り3択・カットインの演出
  - `info.ts` 長押しの説明 / `scene.ts` 空・季節・背景の生き物 / `save.ts` 途中保存と最高記録
- 演出の部品は `src/fx.ts`、効果音は `src/audio.ts`
- イラストは `src/art.ts` の自作SVG
- 画面左上にコミットIDとビルド日時を出している（更新されたかの確認用）
- `main` に push すると GitHub Actions で GitHub Pages にデプロイされる
