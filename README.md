# 🌱 畑スロット

スロットを1回転するたびに畑で1日分の出来事が起き、作物を売った金でスロットそのものを強くしていくゲーム。
外れだらけのスロットを、畑の稼ぎで当たりだらけに育てていく。

## 遊び方

1. 「まわす！」でスロットを回す（1回転＝1日）
2. 手動の出目（🌰種＝1〜3個植えられる・🐝蜂・🌟金の種・🌧️雨・☀️太陽・🧪肥料）をタップ → 畑のマスをタップで使う。☀️はタップだけで全作物に効く
3. 自動の出目（🐦カラス・🪙金貨）は止まった瞬間に効果が出る。カラスは1/2の確率で作物を食べる
4. 実った作物をタップで売る
5. 稼いだ金でスロットを強化（絵柄を足す・カラスを消す・リールを増やす）
6. 7日ごとに年貢を自動で徴収。払えなければゲームオーバー。納めるとお守りを3つから1つ選べる（重ねると強くなる）。代わりに虫が1枚増える
7. 同じ絵柄が3つ以上そろうとフィーバー（効果2倍）
8. 縦・横・斜めに実が並ぶと「そろい」。1つタップで列ごと売値×1.5でまとめて売れる

追加の絵柄：🐝蜂（マスと上下左右が成長）、🧑‍🌾商人（その日の売値×1.5）、🍀四つ葉（翌日 金の種が出やすい）、🐛虫（成長−1）

## 遊ぶたびに増える要素

- 遊び終わると「到達日数＋年貢の納付回数×5」の豊穣ポイントがたまる
- 準備画面でポイントを使い、ショップに並べる「足す」強化（種・肥料・蜂・商人・金の種・四つ葉）やレアのお守りを解放する。最初は太陽と雨だけ
- 毎回、コスト上限の範囲でショップに並べる強化を選んで組む。上限もポイントで広げられる
- リールはレアのお守り「からくり職人」でだけ増える（最大5本）
- 年貢を8回納めればクリア（ポイント+30）。続けるとエンドレス
- 途中で閉じても準備画面の「続きから」で再開できる。？ボタンで遊び方・図鑑
- カラス・虫を消す価格は、消すたびに2倍になる

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック＋ビルド（dist/）
npm run sim      # 貪欲ボットでバランス確認（npm run sim -- 5000 で回数指定）
```

- 調整用パラメータはすべて `src/config.ts` にまとめている（感想フォームのURLは `FEEDBACK_URL`）
- イラストは `src/art.ts` の自作SVG
- ルール本体は `src/game.ts`（画面に依存しない）、画面と演出は `src/main.ts` / `src/fx.ts` / `src/audio.ts`
- `main` に push すると GitHub Actions で GitHub Pages にデプロイされる
