# 🌱 畑スロット

スロットを1回転するたびに畑で1日分の出来事が起き、作物を売った金でスロットそのものを強くしていくゲーム。
外れだらけのスロットを、畑の稼ぎで当たりだらけに育てていく。

## 遊び方

1. 「まわす！」でスロットを回す（1回転＝1日）
2. 手動の出目（🌰種＝1〜3個・🌟金の種・🌧️雨・☀️太陽・🧪肥料・🐝蜂）をタップ → 畑のマスをタップで使う
3. 自動の出目は止まった瞬間に効果が出る：🪙金貨、🧑‍🌾商人（次に売る作物×2をため置き）、🍀四つ葉（次の回転で金の種確定）、🐦カラス（1/2で作物を食べる）、🐛虫（成長−1）
4. 実った作物をタップで売る。縦・横・斜めに実が並ぶと列ごと売値×1.5でまとめて売れる
5. 次の日へ進む前に、毎日3枚から1枚を選んで絵柄袋に入れる（ドラフト）。選び直し（有料）とスキップ（+3金）もできる
6. ショップでは絵柄を消す（カラス・虫など）とリールを増やすができる
7. 同じ絵柄が3つ以上そろうとフィーバー（効果2倍）。カラス・虫がそろうと「群れ」になって危険
8. 7日ごとに年貢を自動で徴収。払えなければゲームオーバー。納めるとお守りを3つから1つ選べる（重ねると強くなる）が、虫が1枚増える
9. 年貢を8回納めればクリア。その後はエンドレスで続けられる

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック＋ビルド（dist/）
npm run sim      # 貪欲ボットでバランス確認（npm run sim -- 5000 で回数指定）
```

- 調整用パラメータはすべて `src/config.ts` にまとめている
- ルール本体は `src/game.ts`（画面に依存しない）、画面と演出は `src/main.ts` / `src/fx.ts` / `src/audio.ts`
- `main` に push すると GitHub Actions で GitHub Pages にデプロイされる
