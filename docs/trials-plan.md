# 試練のセット（案・未実装）

3つの仕組みで「考える要素」を足す。罰として起きるもの（年貢の条件・殿様の気まぐれ）は見返りなし。自分で選ぶ縛り（契約）には見返りがある。

## 1. 契約（自分で縛る・見返りあり）

- **いつ**：毎週月曜の朝、回す前に「今週の契約」が3つ並ぶ。1つ受けるか、受けないかを選ぶ（受けなくてもよい）
- **見返り**：日曜の年貢を納めたあとにもらえる（その週を越えられたら）
- **見せ方**：受けた契約は曜日の表示の下に小さな札で出し続ける（★と縛りの絵）
- **出やすさ**：★1が多く、★3はまれ。同じ週に同じ縛りは並ばない

| ★ | 名前 | 縛り（今週ずっと） | 見返り |
|---|---|---|---|
| ★ | 曇り続き | 太陽は1マスだけ育てる | +30 |
| ★ | 種の節約 | 種は1枚で2個まで | +30 |
| ★ | カラスの渡り | カラスの食べる確率が2倍 | 袋のカラスを1枚消す |
| ★ | 物価高 | 市の値段が×1.5 | +30 |
| ★ | 長雨 | 畑の右端の1列が水びたし（植えられない） | 堆肥のマスを1つ |
| ★★ | 日照りの誓い | 雨が効かない | 満月（レア仕入れ） |
| ★★ | 斜めの風 | 列は斜めだけ数える | お守りの3択 |
| ★★ | 目利きの客 | 単品は売れない | +60 |
| ★★ | 市が閉まる | 今週の市が開かない | 次の年貢−30% |
| ★★ | 虫の大発生 | 毎朝、袋に虫が1枚入る（日曜に全部いなくなる） | 鶏小屋を1つ |
| ★★★ | 壊れたリール | リールが1本少ない | レアのお守りの3択 |
| ★★★ | 忙しい週 | 使える出目は1日2つまで | 畑を1回広げる（タダ） |
| ★★★ | 市場休み | 作物を売れるのは土日だけ | +100 |
| ★★★ | 霧の週 | リールが1つ、止まるまで見えない上に、その出目は使えない日がある | リール+1（ずっと） |

※ 霧の週の見返りは強いので、出るのは難しい3以上だけにする案。

## 2. 年貢の条件（罰・見返りなし）

- **いつ**：その週の年貢に、作物で納める分が付く。月曜に予告し、年貢の札に「＋トマト 2/5」のように出る
- **数え方**：その作物を売るたびに数える（売ったお金は入る）。日曜までに届かなければ、足りない分だけ年貢が増える（1つにつき +20%、上限 +60%）。払えなければ終わり
- **作物は袋で育てられる物から選ぶ**（持っていない作物は出さない）

| 条件 | 例 |
|---|---|
| 作物の数 | トマト5つ／苺8つ／かぼちゃ2つ |
| 列で売る | 列で3回売る |
| 同じ作物の列 | 同じ作物だけの列で2回売る |
| 大物 | かぼちゃかスイカを1つ |
| 日曜に残す | 日曜の終わりに、実った作物を3つ畑に残しておく（売らずに見せる） |

## 3. 殿様への年貢（最終週・罰・見返りなし）

- **いつ**：7回目の年貢の週（クリアの週）。月曜の朝に殿様が出てきて、気まぐれを1つ言う（カットイン）
- **見せ方**：年貢の札が「殿様への年貢」に変わり、殿様の顔が付く。日曜に払えたら殿様が満足の顔でクリアの演出、払えなければ怒りの顔
- **殿様の絵**：ふつう（えへん）・怒り・満足の3つの表情（下書き：docs/img/lord-draft.png）

| 気まぐれ | 中身 |
|---|---|
| 大物を見せよ | かぼちゃかスイカを2つ納める |
| 甘い物を所望じゃ | 苺かメロンを合わせて8つ納める |
| 派手好き | 列で売らない作物は、いつもの半値のさらに半分 |
| 質素倹約 | 今週の市は開かない |
| せっかち | 年貢は土曜の終わりに前倒し |
| 見回り | 毎晩、家来が実った作物を1つ持っていく（かかしで防げる） |
| 豊作を見たい | 日曜の終わりに、畑の半分以上に作物が植わっていること |

## 4. 難しさとの組み合わせ（案）

| 難しさ | 契約 | 年貢の条件 | 殿様 |
|---|---|---|---|
| ふつう | あり（★1〜2） | なし | 7週目に気まぐれ1つ（軽いものから） |
| 難しい1 | あり | 3・5週目 | 同上 |
| 難しい2 | あり | 毎週（2週目から） | 気まぐれ1つ（どれでも） |
| 難しい3 | あり（★3も） | 毎週 | 4週目にも殿様（気まぐれ1つ） |
| 難しい4 | あり | 毎週 | 気まぐれ2つ重なる |
| 難しい5 | あり | 毎週 | 気まぐれ2つ＋増えるイナゴ |

今の「年貢×1.3」「ショップ×1.3」などの数字の上乗せは、置き換えるか残すかを、自動プレイで強さを見てから決める。
