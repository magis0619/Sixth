# 参照ゲームと「盗むもの」

見た目や手触りを決めるときは、ここに書いた3本に照らして判断する（デフォルトの見た目に流れないように）。

> 注意：この文書は文章の資料と記憶から書いた。各ゲームの画面写真はまだ見比べていない（作業環境から画像を取れなかった）。
> 写真で確かめたら、合っていない所を直すこと。

## Luck be a Landlord（同じ「スロット × 絵柄袋 × 家賃」）

- **絵柄どうしの効果は、1つずつ順番に光らせて足していく。** 全部いっぺんに出さない。どの絵柄が何をしたかが目で追える
- **数字は、出した場所から財布へ飛んでいく。** 金額の出どころが分かる
- **家賃（年貢）までの残りが常に見える。** 残り回数と必要額を、いつも同じ場所に
- 絵柄の説明は短い文と数字だけ。長押し・ホバーで詳しく

## Balatro（数字が積み上がる気持ちよさ・押し心地）

- **点数は順番に積み上げる：** 基本 → 1つずつ効果が乗る → 合計。それぞれに音と揺れ
- **数字はスロットのリールのように桁ごとに回って止まる**
- **ボタン・カードは押すと沈み、少し傾き、影が動く。** 置いてあるだけでもかすかに揺れている（ただし揺れは酔う人がいるので、止められるようにする）
- **大きい点ほど画面の揺れも大きく**（点に比例）
- **すべての画面で同じ質感**（ショップもメニューも同じ枠・同じ光）

## Stardew Valley（木と布の温かさ・収穫の「ポン」）

- **枠は木と布。** 角は丸く、影は濃い茶色。白いままの四角は使わない
- **収穫すると作物がポンと跳ね、手元に吸い込まれる**
- **色は暖かい茶・橙・緑。** 冷たい灰色・純白を避ける
- **文字は1つの書体で統一**（丸く太い字。途中で細い字を混ぜない）

## このゲームでの使い方

| 場面 | 参照 | やること |
|---|---|---|
| 列で売る | Balatro・Landlord | 倍率を1つずつ乗せ、最後に合計。金貨は売った場所から財布へ |
| ボタン | Balatro | 押すと沈む・跳ね返る。失敗は赤く揺れて理由をその場に |
| 枠・札 | Stardew | 木と布。札とカードはわずかに傾け、線は手描き風に少し揺らす |
| 年貢 | Landlord | 必要額と残り日数をいつも上に |

## ボタンの状態（全部作り分ける）

| 状態 | 見た目 |
|---|---|
| 通常 | 木・布の枠、影あり |
| 押下 | 指が触れた瞬間に沈む・少し明るく。離すと跳ね返る |
| 無効 | 灰色がかって沈んだまま、押すと理由を出す（何も起きない、にはしない） |
| 成功 | 緑に光って ✓、少し跳ねる |
| 失敗 | 赤く光って小刻みに揺れ、真上に短い理由（「あと12金」「空きマスへ」） |
