## 1. 苺と巣箱　強さ：**強すぎ**
- **目指す形**：巣箱（できれば女王蜂の巣箱）2つの周りを苺で埋め、堆肥のマスの列を通す。
- **序盤**：苺の種を仕入れる。最初の市で巣箱（30）。
- **中盤**：畑を広げて巣箱2つ目。苺の列で10回売ると女王蜂の巣箱に進化。
- **終盤**：堆肥のマスを列に敷き、豊作・欲張りで倍率を足す。
- **合うお守り**：女王蜂の巣箱／欲張り／豊作／カラスの友。
- **弱点**：序盤に巣箱が買えないと遅い。雨が増えて苺の種が出ないと畑が空く。
- **気になる所**：巣箱2つで4×3の畑の全部が「毎晩育つ」範囲に入り、植えた翌日にほぼ実る。4週目から収入が年貢を大きく上回る。

## 2. 蜂と花畑　強さ：未確認
- **目指す形**：苺の列を蜂（斜め）で育て、花畑（蜂＋苺の種＋太陽：苺だけの列 さらに×1.5）をそろえる。
- **序盤**：苺の種・蜂・太陽を仕入れる。
- **中盤**：蜂5枚を女王蜂（斜めの線いっぱい）に合体。
- **終盤**：はちみつ（蜂のフィーバー：作物1つにつき+4）を狙う。
- **合うお守り**：欲張り／豊作。
- **弱点**：花畑は3つそろわないと出ない。蜂は斜めにしか効かない。

## 3. トマトと天気雨　強さ：ちょうど
- **目指す形**：横一列のトマトを、雨（十字）と太陽（縦）で3日かけて育て、同じ作物の列（×1.69）で売る。
- **序盤**：最初の袋のまま。雨・太陽・トマトの種を仕入れる。
- **中盤**：天気雨（雨＋太陽＋トマトの種：重なったマス+1）を狙う。かかしで列を守る。
- **終盤**：トマトの種5枚を鬼トマトの種（売値12）に合体。堆肥のマスを列に敷く。
- **合うお守り**：恵みの雨／日だまり／豊作／畑仕事の名人（広げて長い列）。
- **弱点**：3日かかるので、カラスに狙われる時間が長い。
- **気になる所**：売値を掛け算で伸ばす手（堆肥・鬼トマト・豊作・像）を取らないと、収入が週150〜240のまま伸びず、難しい4の年貢に追いつかない（当時の年貢で211→365→557。2026-11-17に年貢を平らにした）。

## 4. かぼちゃと肥料　強さ：弱い（見立て）
- **目指す形**：かぼちゃ3つの列を作り、肥料（×1.5）を掛けて売る。
- **序盤**：かぼちゃの種・肥料・じょうろ（1マス+2）を仕入れる。
- **中盤**：月を足して、秋の月（かぼちゃの種＋月＋雨：かぼちゃの売値×2）を狙う。
- **終盤**：ランタンかぼちゃの種（合体：4日で実る・60）。
- **合うお守り**：早生／豊作／**秋の実り**（かぼちゃ+50%）。
- **弱点**：かぼちゃは大物ではないので、1個で売ると半値（24→12）。5日かかるので、3つそろえて列にするのが難しい。カラスに食べられないが、つつかれて−20%。

## 5. スイカと堆肥　強さ：未確認
- **目指す形**：2×2のスイカを堆肥のマスの上で育て、1個でも半値にならずに大きく売る。
- **序盤**：トマトや苺でしのぐ。スイカの種は解放が必要。
- **中盤**：畑を4×4以上に広げる。井戸・じょうろで6日を縮める。
- **終盤**：箱スイカの種（合体：5日・220）。
- **合うお守り**：大物狙い（スイカ+50、代償で列の倍率−0.2）／**秋の実り**（スイカ+50%）。
- **弱点**：育つまで収入が少ない。畑を広げるお金が要る。

## 6. 雨と雷　強さ：弱い
- **目指す形**：雨・雷を多めにして、一度にたくさんのマスを育てる。
- **序盤**：雨・雷を仕入れる。雨乞いは最初から恵みの雨つき。
- **中盤**：雷雨（雨＋雨＋雷：雨が斜めにも効く）を狙う。
- **終盤**：大雨・雷神（合体）。
- **合うお守り**：恵みの雨／**雷さま**（雷の成長+1、代償で袋に雑草+2）。
- **弱点**：育てる札ばかりで種が出にくい。合体すると枚数が減って育てる回数が落ちる（雨乞いで雨を合体して崩れたログあり）。

## 7. 太陽の縦列　強さ：未確認

- **中盤**：日だまり（太陽+1）。青天の霹靂（雷＋太陽＋太陽：雷が十字）を狙う。
- **終盤**：真夏の太陽（合体：縦3列）。夏祭り（太陽のフィーバー：売値×2）の日に売る。
- **合うお守り**：日だまり（代償で袋にカラス+2）。
- **弱点**：カラスが増えるので、かかしが要る。

## 8. 月と豊年祭　強さ：未確認

- **弱点**：月はレアで集まりにくい。満月まで3回待つ。

- **終盤**：牛小屋の隣に水路（+2）。
- **合うお守り**：牧場主（収入+2、代償で作物の売値−10%）。

- **序盤**：トマトの列でしのぐ。かかしを置く。
- **中盤**：熟成を取る（代償で実りがカラスに食べられやすい ×1.5）。大かかしまで育てる。

## 13. フィーバー狙い　強さ：未確認

- **序盤**：1種類（例：苺の種）を多めに取る。
- **中盤**：市でお邪魔を消して袋を締める。卵→ツバメで虫を追い出す。
- **終盤**：からくり職人（リール+1、代償で年貢+20%）／からくりリール（240）。
- **合うお守り**：**大判振る舞い**（大当たり×2、代償でフィーバーのない日は売値−10%）／**断捨離**（捨てる値段半分・市で2回、代償で仕入れが2択）。
- **弱点**：袋が締まるまで時間がかかる。合体すると枚数が減って、そろいにくくなる。

## どのビルドでも足す物

| 物 | 何のため |
|---|---|
| 堆肥のマス（×2） | 列の通り道に敷く |
| 夜に育つ置き物（スプリンクラー・ため池・風車） | 育てる量（このゲームのボトルネック）を増やす。週が進むと市に並ぶ。列を切らない端に置く |
| 要らない札を捨てる | 主力以外の種・金貨・多すぎる育てる札を捨てて、袋を締める。捨てるたびに高くなる |
| 畑を広げて長い列 | 4つの列で×1.5、5つで×1.8。広げるほど、どのビルドでも売値が伸びる |
| かかし→大かかし | カラス・虫・雑草から列を守る。追い払うたびに+1。大かかしはカラスが出た日に袋のカラスを1枚追い出す |
| タカ（仕入れ） | 出るたびに袋のカラスを1枚追い出す。カラスが増える難しい3以上やカラスの友のときに袋を締める |
| 市でお邪魔を消す | 袋を締める（1回の市で1枚） |
| 豊作・豊穣の像 | 売値をまとめて上げる |
| カラスの友 | カラスが食べず、来るたびに+3（**強すぎ**：取るとお邪魔がほぼ効かなくなる） |
