# 畑スロット SVG の描き方の筋

参考：Microsoft Fluent Emoji（Flat）、Google Noto、Twitter Twemoji、OpenMoji、game-icons（絵文字にない農具・建物）。
npm の @iconify-json/* から取得して、今の絵と横に並べて見比べた。

## A. 形（参考に合わせる）
1. 現物の「それと分かる特徴」を必ず入れる（参考の3つ以上に共通する特徴）。
   例：トマト＝横長で上がくぼむ・星形のヘタ、苺＝丸い逆三角・種のつぶ・ギザギザのヘタ、四つ葉＝ハート形の葉4枚、
   かかし＝十字の棒・帽子・袖から藁、井戸＝屋根・滑車と桶・丸い石積み、蜂＝縞の丸い胴・透けた羽・触角。
2. 24px でもシルエットだけで何か分かる（細かい模様に頼らない）。
3. 名前と効果に合ったモチーフにする（同じ絵を別の意味に使い回さない）。

## B. 線
4. 外形だけ濃い茶（#3d3326）3px・角丸。内側の描き込みは 2px 以下か、色の差で表す。
5. 線の太さはどの絵も同じ（縮小率を変えて線が細く/太くならないように、入れ子の scale は袋の窓だけ）。

## C. 色と陰影
6. 1つの面は「地の色・影色（下か右）・ハイライト（左上）」の3段。影は輪郭の内側に収める。
7. 色は共通のパレットから。同じ物は同じ色（金は金、カラスの黒は黒）。
8. 背景（土・木・クリーム色）の上で埋もれない明るさ。暗い色の物は輪郭の内側に少し明るい縁取り。

## D. かわいらしさ
9. 生き物と太陽・月・雲の一部には顔：黒い点目＋白い光点、小さい口、頬紅。作物と道具には顔を付けない（畑で並んだときうるさくなる）。
10. 角は丸く、頭身は低く（頭・本体を大きく）。

## E. 大きさと置き方
11. 64×64 の中で、絵の重さ（塗りの量）がそろうように 6〜58 に収める。上下左右のはみ出しなし。
12. 鳥・蝶の羽は class="wing"（羽ばたきの動き）を残す。羽の付け根を今と同じ位置に（鳥 32,30 / 蝶 32,32）。
