# 畑スロット ルール（現行版）

数値はすべて `src/config.ts`、処理は `src/game.ts`。この文書はコードから書き起こしたもの。食い違ったらコードが正しい。

---

## 1. ゲームループ

### 1日のループ（1回まわす＝1日）

| 順 | 段階 | 中身 | コード |
|---|---|---|---|
| 1 | 回す | 袋からリールの本数だけ絵柄を引く（初期3本・最大5本）。同じ絵柄が3つ以上ならフィーバー。組み合わせを判定。今日の仕入れを3つ用意 | `drawDay` |
| 2 | 自動の絵柄 | 止まった瞬間に効く（金貨・商人・四つ葉・カラス・虫・雑草・タヌキ・霜・モグラ・イナゴ）。良い絵柄のフィーバーは役と大当たり | `resolveAuto` `resolveFever` |
| 3 | 手動の出目 | 出目をタップしてマスに使う（植える・育てる・肥料・耕す）。使い残しは日が終わると消える | `useSymbol` |
| 4 | 売る | 実った作物をタップ。縦・横・斜めに3つ以上並んだ実はまとめて高く売れる | `sell` |
| 5 | 仕入れ | 看板の3つから1つをタダで袋に入れる（選ばなくてもよい。翌日には消える） | `takeOffer` |
| 6 | ショップ | 畑の品（道具・土地）を買って置く、お邪魔を消す、畑を広げる | `buy` `buyPlace` `expand` |
| 7 | 日を終える | 夜の成長（井戸・水路・水車・巣箱の苺）と夜の収入（水車・釣り堀・鶏小屋・牛小屋）、熟成。霜が1日溶け、雑草が広がる。7日目ごとに年貢 | `endDay` |

3〜6の順番は自由。

### 1週のループ（7日）

1. 週の始めに、注文が1件と、今週ショップに並ぶ畑の品3つが決まる。お邪魔を消せる回数（週1回）も戻る。
2. 7日目の終わりに年貢を自動で納める。払えなければゲームオーバー。
3. 納めると、次のことが起きる。
   - お邪魔が袋に増える。
   - お守りを3択から1つ選ぶ。
   - 回数によっては「首の皮」が付く。

### 1プレイのループ

- 年貢を7回納める（49日目）とクリア。そのあとはエンドレスで続く。
- 年貢を払えなかった時点で終わる。

### プレイの外のループ

1. 終わると豊穣ポイントが入る（日数×0.5 ＋ 年貢の回数×3、クリアで＋20）。
2. 「解放」の画面で、次のものを開ける。
   - 仕入れに出る絵柄
   - レアのお守り
   - 準備画面の枠
3. 準備画面で、出やすくする絵柄を選ぶ（枠のコスト内。選んだ絵柄は仕入れに2倍出やすい）。
4. クリアすると、1つ上の難しさが開く。

## 2. 絵柄（袋に入っている札）

最初の袋は全部で9枚。

| 絵柄 | 枚数 |
|---|---|
| トマトの種 | 3 |
| 雨 | 2 |
| 太陽 | 1 |
| カラス | 2 |
| 金貨 | 1 |

### 手動（タップして使う）

| 絵柄 | 効果 | フィーバー（3つ以上） |
|---|---|---|
| トマトの種 | 2〜4個植える（2個40%・3個40%・4個20%） | 今日植える分は1段階育った状態から＋大当たり |
| 苺の種 | 3〜5個植える | 同上 |
| かぼちゃの種 / メロンの種 | 1個植える | 同上 |
| スイカの種 | 1個植える（2×2マス） | 同上 |
| 金の種（レア） | 金のとうもろこしを1個植える | 大当たり×3 |
| 雨 | 縦横十字に成長＋1 | 全作物に成長＋1 |
| 太陽 | 縦一列に成長＋1。霜も溶かす | 今日の売値×2 |
| 雷 | 横一列に成長＋2 | 全作物に成長＋1 |
| 蜂 | 斜めに成長＋1 | 作物1つにつき＋4 |
| 鍬 | 横一列の雑草と霜を消して耕す（次に植えた作物が成長＋1） | 畑全体を耕す |
| 肥料 | 作物1つの売値×2 | 畑の全作物に肥料 |
| 満月（レア） | 全作物に成長＋1 | 全作物に成長＋1 |

### 自動（止まった瞬間に効く）

| 絵柄 | 効果 | フィーバー |
|---|---|---|
| 金貨 | ＋3 | 大当たり×3 |
| 商人 | 今日の売値×1.5 | 実った作物を今すぐ×2で全部買い取る |
| 四つ葉 | 翌日、金の種が出やすくなる（袋になくても出る） | お守りを1つ選べる |

### お邪魔（自動）

フィーバーすると「群れ」になり、効果が2倍になる。

| 絵柄 | 効果 |
|---|---|
| カラス | 作物1つを1/2の確率で食べる。かぼちゃとスイカは平気。かかしの近くは追い払う |
| 虫 | 成長−1（鶏小屋の周りでは食べられる） |
| 雑草 | 空きマスに生えて、毎晩1/2の確率で隣へ広がる。抜くのは3 |
| タヌキ | 実った一番高い作物を盗む。実った作物がなければ所持金の10%（最低3）。かかしの近くには来ない |
| 霜 | 1マスを3日凍らせる（植える・育つ・売るができない） |
| モグラ | 作物を隣の空きマスへ押し出す（鶏小屋の周りでは逃げる） |
| イナゴ（難しい5） | 育ち中の作物の成長−1。出るたびに1/2の確率で袋に1匹増える |

## 3. 作物と売値

| 作物 | 実るまで | 売値 | 特徴 |
|---|---|---|---|
| 苺 | 2 | 4 | 巣箱の周りで毎晩育つ |
| トマト | 3 | 6 | |
| かぼちゃ | 5 | 24 | カラスに食べられない |
| メロン | 6 | 45 | |
| 金のとうもろこし | 3 | 30 | |
| スイカ | 6 | 90 | 2×2マス、カラスに強い、列に入らない |

### 列の倍率

| 状態 | 倍率 |
|---|---|
| 列に入らない単品 | ×0.5（難しい4は×0.3） |
| 縦・横・斜めに3つ以上並んだ列 | ×1.3 |
| 同じ作物だけの列 | さらに×1.3 |
| 列が交わる | 2本目から1本ごとに＋15% |
| 大物（スイカ） | ×1（単品でも半値にならない） |

### 売値の計算

（基本の値段 ＋ お守り ＋ 熟成 ＋ 巣箱） × 肥料 × 堆肥 × 今日の倍率（商人・夏祭り） × 彩りの畑 × 組み合わせ × 列の倍率

- **彩りの畑**：実った作物が4種類以上あると、売値＋10%。
- **大豊作**：畑の植えられるマスを全部（9つ以上）一度に売ると、1プレイに1回だけ大当たり。

## 4. 組み合わせ（同じ日のリールにそろうと、その日だけ自動で起きる）

| 組み合わせ | 必要な絵柄 | 効果 |
|---|---|---|
| 雷雨 | 雨＋雷 | 雨が斜めにも効く |
| 天気雨 | 雨＋太陽 | 雨と太陽が両方当たったマスに＋1 |
| 月の宴 | 満月＋太陽 | 満月がさらに＋1 |
| 花畑 | 蜂＋苺の種 | 苺だけの列がさらに×1.5 |
| 青天の霹靂 | 雷＋太陽 | 雷が縦にも効く（十字） |
| 種まき日和 | 鍬＋トマトの種 | 今日植える作物は成長＋1から |
| 秋の月 | かぼちゃの種＋満月 | かぼちゃの売値×2 |
| 商売繁盛 | 商人＋金貨 | 金貨の額×2 |
| 豊年祭 | 雨＋太陽＋満月 | 全部の売値×1.5 |

- 組み合わせは最初は秘密。一度そろうと図鑑に載る。
- トマト祭りは廃止した。

## 5. 袋を変える手段

### 仕入れ（毎日・タダ）

- 解放済みの絵柄から3つ並ぶ。準備で選んだ絵柄は2倍出やすい。
- 8%の確率で、レア（満月か金の種）が1つ混ざる。
- レアは準備画面でもショップでも選べない。

### ショップ（いつでも）

- **畑の品**：週替わりで3つ並ぶ。うち1つは、まだ買っていない「作戦が変わる品」。同じ物は買うたびに1.5倍高くなる。
- **お邪魔を消す**：消すのは週に1回まで。消すたびに2倍高くなる。イナゴだけは回数制限なしで、1.15倍ずつ上がる。
- **畑を広げる**：3×3 → 4×3 → 4×4 → 5×4 → 5×5 の順で、値段は70・130・220・340。

### 畑の品

| 品 | 値段 | 効果 |
|---|---|---|
| かかし | 20 | 周り8マスを守る（働くと大かかしに進化） |
| 井戸 | 60 | 上下左右を毎晩＋1（進化すると黄金の井戸） |
| 巣箱 | 30 | 周りの売値＋2、苺が毎晩育つ（進化すると女王蜂の巣箱） |
| 鶏小屋 | 60 | 毎晩＋2。虫とモグラよけ |
| 牛小屋 | 120 | 毎晩＋4。隣に水路があると＋2 |
| 堆肥のマス | 35 | 売値×2 |
| 水路のマス | 30 | 毎晩＋1。3つ並ぶと水車になる。4方を囲むと釣り堀になる |

- **牧場**：鶏小屋・牛小屋・巣箱がすべてそろうと、3つの効果が2倍になる。

## 6. 年貢・お邪魔・お守り

### 年貢

- 7日ごとに納める。額は 5 → 25 → 80 → 185 → 280 → 380 → 475 →（クリア後）570、そのあとは×1.5ずつ増える。

### 年貢で袋に増えるお邪魔

| 年貢の回数 | 増える枚数 | 増えるお邪魔 |
|---|---|---|
| 1〜2回目 | 1枚 | 虫か雑草 |
| 3〜4回目 | 1枚 | 虫・雑草・霜・タヌキ・モグラ |
| 5〜6回目 | 2枚 | 上の5種＋カラス |
| 7回目から | 3枚 | 同上 |

### お守り

- 年貢のあとに3択から選ぶ（コモン10・アンコモン5・レア1.5の重み）。
- 同じお守りを3個そろえると金色になり、効果が2倍になる。

### 出来事でもらえるお守り

| お守り | 条件 | 効果 |
|---|---|---|
| カラス返し | カラスに5回食べられる | カラスが来るたびに＋3 |
| 首の皮 | 3回目以降の年貢で、残りが10以下 | 次の年貢が半分 |
| 大豊作 | 畑いっぱいを一度に売る | 1プレイに1回の大当たり |

品評会は一時停止中。

### 注文

- 週に1件。袋で育てられる作物のどれかを決まった数売ると、報酬が入る。

## 9. 破綻チェック（2026-10-30）

### 確かめ方

- **ランダム操作**：3000プレイ（初回の状態と全部解放した状態 × 6段階の難しさ）。毎日、次のことを確かめた。
  - お金が負やNaNにならない。
  - 袋の枚数が負にならず、袋が空にならない。
  - 畑の外に作物がない。道具と作物が同じマスにない。
  - 「使える」と出た出目が実際に使える。
  - 仕入れに同じ品が2つ並ばない。
  - 仕入れ中に、ショップで絵柄を足せない。
  - 消えたトマト祭りが起きない。
  - 例外が起きない。
- **自動プレイ（smart）**：初回の状態・全部解放・難しい1〜5で、それぞれ300〜400回。

### 結果

| 確認 | 結果 |
|---|---|
| 不変条件・例外 | 違反0件 |
| 詰み | なし（終わり方は年貢を払えないときだけ） |
| レアの混ざる率 | 8.1%（設定どおり） |
| 初回の状態 | クリア7%、p50で35日 |
| 全部解放 | クリア1%、p50で28日 |
| 難しい1〜5（初回の状態） | 2% / 1% / 0% / 0% / 0% |

### 直したもの

- 廃止したトマト祭りが「解放」画面の特別なお守りの数に入ったままで、全部集められなかった。
- 「満月はショップに並ぶ」という古い説明が残っていた。

### 要相談（ルールを変えるので未着手）

1. **初回は仕入れが雨と太陽しかない**
   - 解放済みが2つだけなので、約半分の日は3択でなく2択になる。
   - 種を足す手段がない。
   - 9個の組み合わせのうち6個は、そもそも出せない。
2. **解放するほど弱くなる**
   - 全部解放（1%）が初回の状態（7%）より弱い。
   - 仕入れの候補が増えて、欲しい絵柄（雨・太陽）が並びにくくなるため。
   - 準備で選んだ絵柄の出やすさ（2倍）では足りていない。
3. **満月が要る組み合わせ（月の宴・秋の月・豊年祭）がほぼ出ない**
   - 豊年祭は1500プレイでたった8日。
   - 図鑑の「見つけた n / 9」が埋まらないと感じられそう。
4. **難しい3以上が厳しい**
   - 自動プレイではクリア0%（自動プレイは人より下手なので、目安として）。
