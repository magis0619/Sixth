# AIっぽさを避けるための点検表

画面を作ったら、この表で見直す（ネットの「AIが作ったUIの見分け方」の要約から作成）。

| 目印 | このゲームでの決め |
|---|---|
| 既製の丸いボタン・iPhone風スイッチ・標準スライダー | ボタンは輪郭線つきのベタ塗りの札。スイッチと目盛りも同じ描き方 |
| ぼかした影＋細い枠（どこでも同じ） | 影はぼかさず、ずらすだけ。枠は絵と同じ濃い茶（--ink）の線 |
| 何でも白い角丸カード、カードの中にカード | 一覧は破線で区切る。カードは重ねない |
| 絵文字・汎用アイコンの混在 | すべて自作の絵（art.ts）。→ ✓ などの文字記号だけは可 |
| 派手なグラデーション・光沢・グロー | 面はベタ塗り＋絵と同じ立体の塗りだけ。帯や札にグラデーションを使わない |
| 装飾だけの縞の繰り返し | 日よけの縞は一番上に1回だけ |
| 真ん中に積んだだけの平均的な配置 | タイトルは景色の中の看板。少しの傾き・不ぞろいな角の丸み |

導入前の見た目に戻すときは、style.css の末尾の「絵と同じ描き方にそろえる」以降を外す。

## unslop（@heydamir）の診断リストで点検（2026-11）

[unslop](https://github.com/heydamir/unslop)（Damir Sokolovsky, CC BY 4.0）の「AIっぽさのサイン」で全画面を診断し、磨きモードで直した。スキルは手元で読んだだけで、リポジトリには写していない。
ゲームに合わない項目（背景を灰色に・「！」を全部なくす・動き続ける演出を全部なくす・弾む動きの禁止）は外した。

- 文字の大きさ：12/14/16/18/22/28px の6段（32px以上の見出し・数字は別）。12px未満はなし
- 太さ：本文500・強調800。Mochiy Pop One を偽の太字にしない（font-synthesis: none）
- 角の丸み：4/8/12/20px。文字の札は8px、ボタンは12px。丸い玉の形は雲・進み具合の棒・切り替え・点だけ
- 選択中の光るぼかし → 墨の太い枠（0 0 0 3px var(--ink)）
- 「！」は大きな出来事（解放・金色・進化・大豊作・フィーバー・リーチ・レア・列そろい・クリア）だけ
- 待っている間に動き続けるのは、そのとき押してほしい1か所だけ。窓が開いている間は後ろの台を止める
- 測り方：`MEASURE=1 npm run audit -- 出力先 p430` で、見えている文字の大きさ・太さ・角の丸み・動き続けている演出・グラデーションを measure.json に数える
